# GC-MS 混合物识别 Web 工具 — 使用说明

---

## 快速启动

```bash
cd webapp
python app.py
```

浏览器打开 http://127.0.0.1:5000

---

## 环境要求

```bash
pip install flask torch scipy numpy pandas openpyxl matplotlib scikit-learn
```

如遇 `ModuleNotFoundError`，安装缺失的包即可。

---

## 使用步骤

1. 打开浏览器访问 `http://127.0.0.1:5000`
2. 点击上传区域，选择 `.xlsx` 或 `.xls` 格式的色谱数据文件
3. 点击"开始识别"
4. 查看结果页面：
   - **成分识别**: 两种组成成分及置信度
   - **比例预测**: 两种成分的比例（仅供参考）
   - **Top-3 候选**: 每个 head 的前 3 名候选
   - **色谱图**: 上传数据的可视化

---

## 输入文件格式

Excel 文件需包含以下两列（列名模糊匹配）:

| 列名 | 说明 |
|------|------|
| 含 `RT` 或 `保留时间(分钟)` | 保留时间，单位: 分钟 |
| 含 `归一化强度(10^8)` 或 `Intensity` | 信号强度 |

支持的格式:
- A 组数据: 2 列（保留时间, 归一化强度）
- B 组数据: 2 列（保留时间, 归一化强度）
- 叠加谱数据: 4 列（RT, Intensity, Ratio1, Ratio2），只使用前两列

数据会自动插值到 4-50 min 范围、1000 个均匀采样点。

## 切换模型

默认加载 CNN 基线模型。如需使用其他模型，通过环境变量指定:

```bash
# 使用 CNN+漂移 模型
set MODEL_PATH=F:\样本叠加测试\outputs\cnn_r80_orderinv_drift\best_model.pth
python app.py

# 使用 Transformer 基线模型（需修改 inference.py 的模型类）
# 注意: Transformer 模型需要 OverlayTransformer 类，当前 inference.py 仅包含 OverlayCNN
```

可用的 CNN 模型:
- `outputs/cnn_r80_orderinv/best_model.pth` — 基线（推荐）
- `outputs/cnn_r80_orderinv_drift/best_model.pth` — 加漂移增强
- `outputs/cnn_r80_orderinv_noise/best_model.pth` — 加噪声增强
- `outputs/cnn_r80_orderinv_drift_noise/best_model.pth` — 漂移 + 噪声

## 结果解读

### 可信度高的结果
- **成分识别**: 模型在合成数据上 either-order 准确率 ~99%，成分识别结果通常可靠
- **置信度**: 高于 90% 时结果比较可信

### 需谨慎对待的结果
- **比例预测**: 当前模型比例预测能力有限（MAE ~0.20），尤其极端比例（如 1:9）误差大
- **模型基于模拟数据训练**: 未在真实混合样品上验证，实际使用时结果可能有偏差

## 常见问题

### 1. 启动报错 `ModuleNotFoundError`
```bash
pip install flask torch scipy numpy pandas openpyxl matplotlib scikit-learn
```

### 2. 模型加载失败 `size mismatch`
样本目录文件数与模型训练时不一致。确保 `GCMS_单个样本数据/` 目录下的文件数量与模型匹配。
当前模型基于 9 种样本训练，推理时自动从 `A_names.npy` 加载正确的样本名。

### 3. 上传文件后报"无法识别 RT 或强度列"
检查 Excel 文件的列名是否包含 `RT`/`保留时间(分钟)` 和 `Intensity`/`归一化强度(10^8)`。

### 4. 想用 Transformer 模型
需要在 `inference.py` 中添加 `OverlayTransformer` 和 `PositionalEncoding` 类定义（可从 `CNN_Transformer.py` 复制），并修改 `GCMSPredictor.__init__` 中的模型实例化代码。

## 维护说明

### 添加新样本
1. 将新样本的 `.xlsx` 色谱文件放入 `GCMS_单个样本数据/`
2. 重新运行 `CNN.py` 训练（会自动检测新样本数量）
3. 新模型会保存到 `outputs/` 对应目录
4. 重启 webapp 即可加载新模型

### 清理生成的图表
`webapp/static/` 目录下的 `.png` 文件是每次预测生成的色谱图，可以定期清理:
```bash
del webapp\static\*.png
```

### 更新模型
1. 训练完成后，将 `MODEL_PATH` 环境变量指向新模型
2. 或直接修改 `app.py` 第 26-28 行的默认路径
3. 确保新模型目录下有 `A_names.npy`（训练脚本自动保存）

### 端口冲突
如果 5000 端口被占用，修改 `app.py` 最后一行:
```python
app.run(host='127.0.0.1', port=8080, debug=True)
```
