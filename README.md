# GC-MS 色谱信号解耦与成分识别引擎 / GC-MS Signal Deconvolution
**企业合作落地探索项目 · 工业级数据科学实践**

## 📖 项目背景 (Project Background)
本项目起因于我参与的一项企业技术需求对接。合作企业需要对复杂的植物精油混合物（如白兰花油、甜橙油、金银花油等一共10种基底原料）进行成分拆解。由于气相色谱-质谱（GC-MS）数据常常出现信号重叠与干扰，传统依靠专家人工比对特征峰的分析方法效率极其低下。

**核心本愿**：希望能够构建一个基于深度学习的算法模型，直接输入 GC-MS 的一维色谱信号数据（RT-TIC 色谱图），实现端到端的“**混合物成分识别**”与“**核心原料混合比例预测**”。

---

## 💡 方案设计与实验探索 (Methodology & Experiments)

由于工业界真实、带有完美标签的混合标注数据难以低成本获取，本项目采用了算法工程中经典的“**仿真基线合成** (Synthetic Data Generation)”路径：

1. **构建大规模合成物理数据集**：
   提取企业的 10 种基础原料油单品色谱，通过不同的排列组合、插值与数十种浓度比例，利用程序自动生成并合成了近 7200 条带标签的高质量模拟混合色谱数据。

2. **多模态与深度学习模型选型**：
   - 将该工业问题正式定义为**多标签分类 (Multi-label Classification) + 比例回归 (Regression)** 的联合学习任务。
   - 独立设计并试验了基于 **1D-CNN** 和 **Transformer (Self-Attention)** 的光谱序列处理算法。
   - 针对排列组合带来的数学歧义，自研了 **Order-invariant Loss（顺序无关损失函数）**，打破了因样本排列导致的信息干扰，使得模型快速收敛。
   - **实验结果**：在合成数据集上，CNN 基线模型达到了 **99.44%** 的成分盲盒识别准确率。尽管 Transformer 达到了微弱优势的 99.86%，但鉴于 CNN 拥有极小的体积 (0.7MB) 与极快的训练/推理速度（约Transformer的5-10倍），最终选择 CNN 架构作为核心生产基线。

3. **数据增强与抗仪器漂移 (Data Augmentation)**：
   为模拟真实环境中的分析机器保留时间（RT）漂移以及底噪，项目中后期引入了随机平移与高斯噪声进行鲁棒性（Robustness）对抗训练并设计了消融实验。

4. **端到端演示系统 (Demo App)**：
   搭建了完整的 Web 前端应用界面服务（包含 Flask 部署端）。业务人员仅需直接拖拽仪器导出的 `.xlsx` 原始色谱文件，系统即会一键输出成分预估和调配比例。

## 🔬 工业界实验反思：Sim2Real 鸿沟 (Lessons Learned)

尽管由于算法加持，上述基线在本地模拟数据集上的指标极其惊艳。但在实际企业交付前夕对**带有真实物理特性的盲测混合数据**进行推理验证时，我们遭遇了严峻的工程挑战：

- **Sim-to-Real 的相关性断层**：因为通过程序线性叠加与插值手段生成的（Synthetic）合成色谱图，未能完美表征自然界中复杂物理化学混合造成的干扰与融合效应（例如物理共流出效应、分子间相互作用导致的保留时间偏移）。
- **高质量落地数据的获取成本**：要进行基于真实域的数据微调（Fine-tuning），需要企业内部建立自动化流水线进行数万次的精密调配、仪器进样、质谱分析，这背后的试错与数据获取成本完全超出了当期的落地预期。

**项目总结**：
由于真实数据缺乏，该合规落地验证最终未能顺利推进下去，项目暂时归档。
但这作为我的独立项目，带给我极大收获——它让我切身实地地体会到了真实工业人工智能落地中的经典困局：**高质量、贴合业务物理本质的数据构建，其决定性意义远远大于单纯的代码与花哨的算法设计**。
这段从“需求沟通、算法选型、数据合成”走向“业务验证碰壁、调整预估”的真实迭代经验，构成了我实践中最宝贵的认知财富。
